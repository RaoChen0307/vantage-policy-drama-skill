# Vantage 政策短视频剧本生成器

## 概述

接收 Vantage Markets 政策动态素材，自动筛选有剧本价值的条目，生成多个差异化故事方向，用户选定后输出可直接用于 AI 视频生成的分镜剧本。

本 Skill 基于短剧创作框架，专为金融平台政策场景定制。

## 输入门

接收来自定时任务的政策推送，包含：
- 政策标题、核心变化点、生效日期、信息来源链接
- 多条动态按重要性排序

**自动筛选规则**（无需用户操作）：
从推送的 5-8 条中，优先选取具备以下特征的政策作为剧本素材：
1. **数字变化大**（如杠杆 100→500、订单量 10 倍）→ 天然有戏剧张力
2. **时间敏感**（如促销即将截止、产品当天下架）→ 制造紧迫感
3. **影响面广**（如 49 只新品上线、全服务器变更）→ 可构建多角色场景
4. **有冲突潜力**（如仅做多限制、股票移除）→ 可构建策略转变剧情

每次选取 **1-2 条**最有价值的政策生成剧本方向。若当天无适合剧情化的政策，直接告知用户"今日政策偏常规，暂不生成剧本"。

## 工作流

### 第一步：政策拆解（Policy Analyst）

对每条选中的政策，内部输出：
- **变化前状态** → **变化后状态**
- **谁受益** / **谁受影响**
- **核心数字**（必须与原始政策完全一致，不得改写）
- **风险提示点**（杠杆类必须标注放大亏损风险）

### 第二步：故事引擎匹配（Creative Director）

政策类型 → 推荐故事引擎映射：

| 政策类型 | 推荐故事引擎 | 示例钩子 |
|---|---|---|
| 杠杆/额度提升 | 逆袭 / 危机处理 | 主角因资金不足错过机会，升级后反转 |
| 新产品上线 | 机会争夺 / 隐藏身份 | 众人争抢新交易品种，主角靠信息差制胜 |
| 股票下架/限制 | 时间压力 / 规则漏洞 | 必须在下架前完成操作，倒计时紧张感 |
| 促销/返现活动 | 竞赛 / 误会反转 | 两人比拼交易量，意外发现返现规则 |
| 交易模式变更 | 策略转变 / 认知差 | 习惯做空的人被迫调整，反而发现新机会 |

**禁止**：把所有政策都套同一个"散户逆袭"模板。不同政策必须用不同因果引擎。

### 第三步：生成方向（默认输出 3 个）

每个方向必须包含：
- 方向名称
- 第一屏压力（静音可懂）
- 主角行动
- 关键证据（政策数字自然植入）
- 反转
- 政策如何改变剧情
- 广告记忆画面
- 结尾回报

**生成后 STOP**，列出 3 个方向让用户选择或组合，不写完整剧本。

### 第四步：用户选定后输出完整剧本

沿用标准分镜格式：

```
《片名》
预计时长：xx秒
人物：角色（年龄、外形、服装、关键道具）
政策依据：[政策标题]（生效日期）

1-1 日/夜 内/外 地点
人物：...
预计时间码：00:00—00:09

△具体、可见、事件级动作。
角色：自然对白。
```

## 金融合规硬门（HARD GATE，任何一条不通过即打回）

1. **不承诺收益**：禁止出现"稳赚""必涨""翻倍"" guaranteed profit"等表述
2. **杠杆双向呈现**：涉及杠杆提升的剧情，必须有一个画面或台词暗示杠杆也放大亏损（如主角提到"亏了也会放大"）
3. **数字零误差**：剧本中出现的杠杆比例、手数、金额、日期必须与原始政策完全一致
4. **促销标注 T&C**：涉及返现/奖金的剧本，结尾画面需有"*条款与条件适用"的视觉提示
5. **不暗示内幕**：主角不能因"知道政策"而获得不公平优势，政策是公开信息
6. **风险提示**：剧本结尾必须有风险提示画面（如"交易有风险，投资需谨慎"）

## 故事因果门

- 政策必须参与剧情因果，不能只是背景板
- 删除测试：移除政策后剧情是否仍然成立？如果成立，植入失败
- 政策不能只在结尾出现，必须在中段制造转折或障碍
- 主角有非政策驱动的原始欲望（如救急、比赛、证明自己）

## 可视化门

- 每个 △ 动作必须能用简笔画画出
- 去掉字幕/UI 后观众仍能看懂剧情变化
- UI 只做辅助证据，不承载核心因果
- 禁止连续三个 Beat 都是"看屏幕/看K线/看手机"

## 对白门

- 角色不知道自己在广告里
- 禁止角色念政策原文或广告话术
- 政策信息通过角色的行动和反应自然呈现
- 精确数字可出现在屏幕 UI 上，不由角色口述

## 输出规范

- 方向阶段：3 个方向，简洁列出，不写完整剧本
- 剧本阶段：干净分镜剧本，不暴露内部推理
- 每次输出末尾标注：**政策来源链接** + **风险提示**
