## 四、vantage-policy-drama Skill 设计

### Skill 位置
`/home/user/.doubao/agent_mode/workspace/.user_skills/vantage-policy-drama/SKILL.md`

### 核心模块

#### 1. 输入门 — 政策自动筛选
从推送的 5-8 条政策中，按以下优先级筛选剧本素材：
- **数字变化大**（杠杆 100→500、订单量 10 倍）→ 天然有戏剧张力
- **时间敏感**（促销即将截止、产品当天下架）→ 制造紧迫感
- **影响面广**（49 只新品上线、全服务器变更）→ 可构建多角色场景
- **有冲突潜力**（仅做多限制、股票移除）→ 可构建策略转变剧情

每次选 1-2 条。无适合的则告知用户。

#### 2. 政策 → 故事引擎映射表

| 政策类型 | 推荐故事引擎 | 示例钩子 |
|---|---|---|
| 杠杆/额度提升 | 逆袭 / 危机处理 | 主角因资金不足错过机会，升级后反转 |
| 新产品上线 | 机会争夺 / 隐藏身份 | 众人争抢新交易品种，主角靠信息差制胜 |
| 股票下架/限制 | 时间压力 / 规则漏洞 | 必须在下架前完成操作，倒计时紧张感 |
| 促销/返现活动 | 竞赛 / 误会反转 | 两人比拼交易量，意外发现返现规则 |
| 交易模式变更 | 策略转变 / 认知差 | 习惯做空的人被迫调整，反而发现新机会 |

#### 3. 金融合规硬门（HARD GATE）

任何一条不通过即打回：
1. **不承诺收益**：禁止"稳赚""必涨""翻倍"等表述
2. **杠杆双向呈现**：涉及杠杆提升必须有画面/台词暗示也放大亏损
3. **数字零误差**：剧本中的杠杆比例、手数、金额、日期与原始政策完全一致
4. **促销标注 T&C**：返现/奖金类剧本结尾有"*条款与条件适用"视觉提示
5. **不暗示内幕**：主角不能因"知道政策"获得不公平优势
6. **风险提示**：剧本结尾必须有风险提示画面

#### 4. 故事因果门
- 政策必须参与剧情因果，不能只是背景板
- 删除测试：移除政策后剧情仍成立 → 植入失败
- 政策不能只在结尾出现，必须在中段制造转折或障碍
- 主角有非政策驱动的原始欲望

#### 5. 可视化门
- 每个 △ 动作必须能用简笔画画出
- 去掉字幕/UI 后观众仍能看懂剧情变化
- UI 只做辅助证据，不承载核心因果
- 禁止连续三个 Beat 都是"看屏幕/看K线/看手机"

#### 6. 输出格式
- 方向阶段：3 个方向，简洁列出，不写完整剧本
- 剧本阶段：干净分镜剧本，不暴露内部推理
- 末尾标注：政策来源链接 + 风险提示
